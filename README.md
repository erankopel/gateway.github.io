# gateway.medicom.vip

Landing, privacy and support pages for the **Gateway Self-Practice** Android app
(Google Play: io.github.erankopel.selfpractice), in the style of udoc.medicom.vip.

- `index.html` — landing page with the Google Play badge and screenshots
- `privacy.html` — the app's privacy policy (same text as the copy hosted in
  erankopel/Gateway-Public-Pages, which the Play Console listing still points to)
- `support.html` — support and FAQ

Screenshots and the app icon are loaded from the existing public pages repo
(erankopel/Gateway-Public-Pages, img/) so this repo stays text-only.

Served by GitHub Pages from `main`, custom domain via the `CNAME` file,
DNS: Cloudflare CNAME `gateway` -> `erankopel.github.io`.
